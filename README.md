# Internal Operations Dashboard

Internal web based operational dashboard for managing Qubriux platform administrative workflows.

This dashboard serves as a centralized internal tool for operational teams to manage merchant related workflows, utilities, and internal processes.

The platform is modular and intended to support multiple internal operational capabilities over time.

Current available module:

- Customer Dashboard QR Code Generator

---

## Overview

The Internal Operations Dashboard is a shared internal application used by authorized Qubriux teams.

Its purpose is to centralize operational workflows into a single controlled interface rather than maintaining separate tooling for each process.

Current functionality focuses on generating customer-facing QR codes for the Qubriux Customer Dashboard.

---

## Current Module: Customer Dashboard QR Code Generator

This module allows internal users to generate QR codes that route customers into the shared Qubriux Customer Dashboard with the correct merchant and store context.

The base url for the customer dashboard is

```txt
https://customer.qbriux.io
```
